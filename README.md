## Установка

### Требования
- Python 3.12+
- Redis
- Ollama (для локальных LLM)

### Установка зависимостей

```
# Создайте виртуальное окружение (если ещё не создано)
python3 -m venv venv

# Активируйте окружение
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```
## Настройка прокси (для РФ)
Telegram API заблокирован в РФ, поэтому боту нужен прокси для работы.

### Вариант 1: Автоподбор прокси (рекомендуется)
Добавьте в `.env`:

```
TELEGRAM_PROXY_AUTO=true
```
При запуске бот автоматически:
Загрузит список прокси из API (по умолчанию proxyscrape).
Проверит первые 20 прокси на работоспособность.
Запустится с первым рабочим прокси.
Если прокси упадёт — автоматически переключится на следующий.
### Вариант 2: Прокси вручную
Добавьте в .env:
```
TELEGRAM_PROXY_AUTO=false
TELEGRAM_PROXY=socks5://IP:PORT
```
#### Где найти прокси
Бесплатные публичные прокси можно найти на:
```
https://www.socks-proxy.net/
https://free-proxy-list.net/
https://proxyscrape.com/free-proxy-list
```
Проверить прокси можно командой:
```
curl -x socks5://IP:PORT https://api.telegram.org
```
Если возвращается {"ok":true,...} — прокси работает.
### Важно
Публичные прокси нестабильны и могут перестать работать в любой момент. Для надёжной работы рекомендуется поднять свой прокси-сервер.
